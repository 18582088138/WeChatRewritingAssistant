## 版本和审稿规则

编号版本基于累计正文变化比例；20% 修改保持原版，恰好 30% 保持原版，31% 新增版本，明确另存也新增。配图/视频路径与脚注不计入正文变化量。小改与媒体变化在当前稿高亮；原阶段快照保留作内部审计，不作为额外人工/AI 版本展示。

提案生成不改正文；确认接口校验并发 revision。窗外点击和 Escape 保存编辑后的提案，放弃按钮保留原段落。审稿缓存测试在移除模型密钥后仍能读取未改稿的审稿结果，证明未重新调用模型；修改后保留旧意见并标记为需要复审。

视频预览新增本地封面帧；FFmpeg 可用时从实际文件提取。不存在 FFmpeg 或封面提取失败时保留视频并记录提示，不伪造视频画面。当前浏览器实测使用 H.264 视频；其他编码的播放能力取决于浏览器和系统。

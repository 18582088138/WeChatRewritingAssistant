# 使用手册

## 安装与一键启动

本机使用 conda 环境 xkd_env_py312。Windows 需已有 conda/Miniforge；项目安装脚本会查找 PATH 和用户目录中的常见安装位置。已有环境不会重建，已有 .env 不会覆盖。

1. 双击根目录 Install.cmd，安装 requirements.txt，并在指定环境不存在时创建 Python 3.12 环境。网络代理需在终端环境配置；安装 Python 依赖时尚未加载 .env。
2. 编辑 .env 填入 DEEPSEEK_API_KEY，已有配置可直接使用。模型密钥、公众号密钥与代理都由后端读取，界面不保存模型密钥。
3. 双击 Start.cmd，启动 GUI 和 API，自动打开 http://127.0.0.1:8000。再次启动时检测已有服务并打开页面，不再启动第二个实例。关闭服务终端停止应用。

无浏览器启动可用：

```powershell
conda run --no-capture-output -n xkd_env_py312 python scripts/launch.py --no-browser
```

Linux 需 Python 3.12，可执行 `sh scripts/install.sh` 和 `sh scripts/start.sh`；本轮只验收 Windows/conda。后续完整部署应选择支持 Python 和持久化目录的平台；Docker 打包入口尚未实测，本轮不部署 Pages。

服务地址与端口在 config/app.json。手机在同一局域网访问时，把 host 改为 0.0.0.0，重启，然后用手机打开电脑局域网 IP 和相同端口；按实际环境允许防火墙访问。默认 host 为 127.0.0.1。设置 APP_TOKEN 时在 GUI“设置与连接”填入访问令牌，同源使用无需配置独立后端地址。

## 导入和生成

在文章工作台点击导入，粘贴公开文章或论文 URL。抓取完成后目录显示原文标题和阶段；点击文章进入操作页面。无法自动访问时可粘贴原文文本并填写标题，仍须保留原文链接。

选择平台、目标篇幅和模型服务，保持关联搜索开启，再点击“生成 + 审稿”。默认篇幅 1800，统一专业、自然、克制。检索以原文发布日期为基准，默认前后 3 天；旧论文或基础资料明确作为背景，不会包装成当日新闻。一般收集 3–5 篇参考；确实只有 1–2 篇可用时继续生成并提示资料较少，不用弱相关资料凑数。

写作和审稿是两个阶段，阶段结果分别保存。Done 表示生成轮结束，仍需查看审稿意见与风险。出现失败提示时，先看原因；来源或模型网络可重试。超长模型输出保存在 generated/attempts，不覆盖现有稿。

## 文案编辑与来源核对

打开已有文案时默认是 Markdown 阅览，图片和视频直接显示。双击正文或点击“编辑文案”进入 Markdown 编辑，可修改标题、一句话总结和正文；关键词在下方草稿投递区修改。参考来源的文章名称和链接单独显示在正文窗口下方，不进入正文或组图，也不计入字数。提交人工阅览的正文会移除 Agent 内部注释、脚注和来源编号，来源证据仍保存在文章元数据与内部尝试稿中。

小幅文字改动、段落重写和配图修改保存到当前版本，并在阅览中高亮。累计正文改动超过 30% 或点击“另存为新版本”才新增编号版本；版本不区分人工和 AI。之前的版本可完整阅览文案、图片和视频。审稿结果不会被清空；当前稿变化后显示上次审稿并提示需要复审。

局部修稿时选中要修改的正文，输入要求，再点“重写选中段落”。生成后弹出前后对比窗口，可以继续编辑新段落。点击“确认修改”或窗口外会保存新段落；按 Escape 同样保存；点击“保留原段落”放弃本次提案。提案生成期间原稿保持不变。配图替换时选中原图片的完整 Markdown，再从本篇或公共素材中选择图片；删除图片或视频时删除相应 Markdown。图文预览按页切换，不需要读一整张超长图。

侧面的“参考资料浮窗”默认只显示本篇文章素材库和公共素材库，可以切换范围，不显示其他文章的素材。选择文章后可查看日期和出处，点击原文链接核对。电脑端选择一段，点“加入选中段落”；可跨页、跨资料继续选择。公共文章的选区会先加入本篇资料包。打开浮窗前把光标放到正文插入位置，最后点“融合改写并插入正文”，调用 LLM 融合后保存。来源编号只用于内部核对，不显示在人工稿中。模型失败或缺少有效出处时原稿保持不变。手机不显示多段资料融合。

## 添加参考材料

浮窗内选择“添加到本篇 / 公共素材库”，再添加网址或文件。网址会抓取正文与媒体；文件支持 Markdown/TXT/PDF/HTML/DOCX、图片和视频。公共素材也可在主导航“素材库”页面添加。该页面按文章分组展示各篇素材，并提供独立公共库。也可直接复制到当前文章目录或 data/public-materials/：

```text
manual/images/    PNG/JPEG/WebP/GIF
manual/videos/    MP4/MOV/WebM
manual/texts/     Markdown/TXT/PDF/HTML/DOCX（纯文本建议 UTF-8）
```

路径在浮窗显示。复制后点“同步文件夹”或重新打开文章；同路径内容不变不会重复导入，内容改变会更新。单文件上限 25 MB。建议文本开头写 `原文链接：https://…`，无链接的文件作为本地材料，不伪装成公开来源。手动 PDF/HTML 导入用于文本，需另添其中需要的媒体。

资料图片/视频可插入内部草稿，界面显示待确认。来源与素材页面可逐项确认授权和水印。不要确认无法判断的素材；导出只包含已确认文件，公众号正文存在未确认图片会提示先处理。图片无法自动证明无水印；外部播放器仅保存链接，不等同于本地视频。

## 审稿和分页组图

审稿面板默认展示最近一次保存的记录，意见较长时在面板内滚动。当前稿未改变时点击审稿只打开保存结果，不再次调用模型；修改后按钮提示重新审稿。点“按审稿意见修改”启动写作与复审。创作设置位于审稿反馈上方。

在编辑模式点“生成 3:4 组图”，先保存编辑，再生成多张 1080×1440 PNG，并切换到素材页。组图包括封面和正文，参考链接独立保存，不画进正文卡片。素材页每次显示 6 项，可翻页查看。确认每页字号、顺序和图片与文字关系；长稿可能有较多页，建议先改成 600–1200 字短稿，再生成适合单次图文使用的组图。

图文生成若提示容量不足，可减少 config/platforms.json 中 card_chars 或缩短过长标题；不会静默裁掉正文。minimum_font_size 至少 26，画布宽高必须 3:4。插图卡片继承图片的待确认状态。

## 平台草稿

选择平台后准备/投递，最终发布自行在平台执行。公众号在 .env 配置 WECHAT_APP_ID/WECHAT_APP_SECRET，设置页填写作者和可选封面 thumb_media_id；权限和账号网络配置满足时应用调用草稿接口。未配置时显示失败，不会假报成功。

X、小红书、微博目前生成本地图文包，再由用户打开平台创建草稿。“素材包已就绪”不代表远程草稿箱已写入。ZIP 含 draft.md、caption.txt、preview.html、sources.json 和已确认素材；发布前再检查各平台实际字数与账号能力。公众号草稿暂不支持本地视频上传，含本地视频的正文会要求先移除嵌入，避免写入无法播放的地址。

## 配置与存储

| 文件 | 调整内容 | 生效方式 |
| --- | --- | --- |
| config/app.json | host/port/open_browser/conda_env | 重新启动；环境名修改后重新安装 |
| config/research.json | window_days/allow_background/数量/下载大小/重试/上下文预算 | 下次搜索与抓取 |
| config/generation.json | 字数、风格、模型参数、超时、压缩重试、图片数量 | 下次生成/审稿，刷新 GUI 读取默认值 |
| config/platforms.json | 组图画布、每页字符、预览字符、最小字号 | 下次预览或生成组图 |
| config/prompts/*.md | 写作/审稿/语言风格/融合/压缩提示词 | 下次模型请求 |
| .env | 密钥、代理、应用令牌、数据路径等 | 重启服务 |

图片/视频数量统一由 research.json 控制，旧 SOURCE_IMAGE_LIMIT/SOURCE_VIDEO_LIMIT 环境项不再生效。不要把密钥放在 config；配置会随生成在本地归档用于复现。风格迭代方法见 [语言风格调参指南](prompt-style-guide.md)。

原文归档在 data/articles/原文标题/，同名任务加短 ID。原文和参考资料分 source/references，每份资料按 text/images/videos 保存，标题 Markdown 开头保留原文链接；生成稿在 drafts，历史状态在 versions，本地素材在 manual。draft.md 兼容旧路径，article.json 是应用当前状态。旧 UUID 目录首次启动会备份并迁移，原素材保留供历史快照使用。

可以在 IDE 打开落盘文案阅览。要让修改进入应用，请通过 GUI 保存；直接修改 drafts 中的 Markdown 目前不会自动回写 article.json。不要在运行中编辑 article.json，以免和任务保存冲突。定期备份 data、config 和私有 .env。

## 常见问题

后端未连接：用 Start.cmd 启动完整应用，访问本地地址。Pages 历史页面只有静态 GUI，本轮完整功能在本地。

资料日期未知或关联搜索为空：查看抓取诊断，人工补充直接相关来源。自动检索是尽力检索，日期和实体筛选可能漏掉相关文章。

部分图片或视频失败：看来源的 media_downloads，确认是否限流、临时网络失败或播放器。更换可公开下载的材料，或使用本地文件添加。

409 冲突：等待处理结束或刷新获取新修订，不用旧窗口反复覆盖。模型失败保留已存稿，可重试或检查 .env、额度及代理。

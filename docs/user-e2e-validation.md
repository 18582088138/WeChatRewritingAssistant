## 完整流程的检查范围

三篇分别执行以下链路，保留各阶段文案与修订快照：

1. 从 URL 创建文章、等待真实抓取；检查正文锚点、发布日期、来源图数量与未授权状态。
2. 联网关联检索与素材保存；真实写作 Agent 输出标题、正文、一句话摘要、关键词、逐项来源；独立审稿 Agent 审核当前修订。
3. Chrome 中打开已保存全文；人工编辑并保存标题，确认修订号递增、旧审稿结果失效。
4. 在编辑框选择段落并调用真实模型重写；断言选区前后的文本完全保留。
5. 上传并确认两张测试自制 PNG，使用实际素材选择器插入、替换图片；检查预览图片加载。
6. 查看修订记录、生成 1080×1440 组图、实际下载 ZIP；检查 1440px 桌面和 390px 手机页面无脚本错误、手机无横向溢出。最终修订预览另在 1440、768、390px 三种宽度核对图片加载并保存截图。
7. 再审当前文案；针对审稿意见真实修改并自动复审；检查修订号与审稿号一致、长段落无完全重复。
8. 修订后重新生成组图，逐张校验尺寸和文件；导出微信公众号、X、小红书、微博四个图文包，检查正文、来源清单、预览图片引用与 ZIP 内文件相符，未确认来源图不进入素材包。
9. 执行四平台投递入口：公众号无配置时明确返回失败，另外三平台返回 `export_ready`。

`passed` 表示上述程序检查成功，不表示文案已达到发布标准。真实审稿分数和意见逐轮记录在本地报告中；不会筛选高分轮次替换低分结果。

## 实测发现与修复

- 自定义请求标识会让两个公众号链接返回验证页。改为仅对公众号使用普通浏览器请求头后，两篇真实正文可取；没有使用登录凭据或验证码绕过。
- 公众号发布时间在脚本 `create_time` 中，作者在 `#js_name`，现正确读取并落盘。
- 整个中文长标题检索命中率低。改为分别检索模型名称，同时收集原文正文中的引用链接，过滤图片、示例音频 API 和 Git 安装命令中的伪链接。
- JAEC 缩写曾匹配日本原子能机构。仅在搜索词增加 `site:` 不足以保证结果域名，现筛选器再次校验限定域名，排除同名机构。
- HTML 段落链接清理曾覆盖来源引用列表变量，导致部分网页元数据无法 JSON 序列化。已修复并添加回归测试。
- 1200 字目标下，真实模型多次输出超限。增加包含实测正文字符数的两轮压缩请求；仍超限则保留原稿并明确失败，不截断文案。语音双模型文章最终使用界面已有的 1800 字档位，其他首轮用 1200 字；按意见修订用 1800 字。目标并非严格字数保证。
- 局部模型重写曾复制选区外的相邻段落，独立审稿发现后进入修改链路；提示词已明确禁止复制未选中上下文。仍保留人工复审与版本恢复能力。
- 修订后的模型曾把旧文案组图嵌回正文，再生成组图会移除旧素材元数据，导致导出丢图。现写作候选排除文案组图，生成新组图保留正文引用的旧图；回归测试验证再次生成后图仍可导出。E2E 增加正文引用数与导出预览图片数一致的断言。

## 边界与人工复核

原文图片全部保留 `approved=false`，没有把“已下载”当作“无水印且有转载许可”。测试插入的是程序自制纯色 PNG，属于操作验证占位图，人工发布前应换成内容相关配图。审稿 Agent 对素材库中未使用但未授权的图片也会提示高风险；该提示不等于素材已被导出。

技术重点需人工回查：FLASepformer 的 8 kHz、双说话人、RTX A800、30 秒条件；JAEC 的 22 ms 是算法延迟，不是端到端通话延迟；DMCA 下架与法院判决、律师函不能混用；MiniMax 第三方榜单的单项领先不能改写为全面领先。非官方 H3 专题站不能代替官方许可证。

公众号外部账号草稿写入没有在本次实测中完成：隔离测试子进程清空公众号 App ID/Secret，测试了配置缺失的失败分支。X、小红书、微博当前实现为素材包交付，`export_ready` 不代表写入平台草稿箱。没有执行公开发布。
